# Migrations

Use the guide for the Nock version you are upgrading to. Each guide summarizes the release changes that may require updates to your runtime or tests.

## 14.x → 15.x

Nock 15 raises the minimum Node.js version to 20.12.1, becomes a pure ES module, and updates request, reply, and event APIs.

[Read the Nock 14 to 15 migration guide](/migrations/14-to-15)

## 13.x → 14.x

Nock 14 raises the minimum Node.js version to 18 and adds interception for native `fetch`.

[Read the Nock 13 to 14 migration guide](/migrations/13-to-14)
